3. Fitur Aplikasi

3.1 Autentikasi & Keamanan

  • Login: Username/email dan password, session-based
  • Signup: Registrasi user baru dengan validasi
  • Password Management: Change password, forgot password, reset password

3.2 Manajemen Tiket

User Features:

  • Create Ticket dengan kategori, prioritas, deskripsi, attachment
  • View Tickets (daftar tiket sendiri)
  • Update Ticket (hanya status "Open")
  • Delete Ticket (hanya status "Open")
  • View Details lengkap dengan attachment

Admin Features:

  • View All Tickets (semua tiket)
  • Update Ticket (status, prioritas, assign, dll)
  • Delete Ticket (semua tiket)
  • Assign Ticket ke admin lain
  • Ticket Statistics dashboard

3.3 Form SDLC

Fitur khusus untuk kategori "Pengajuan pembuatan atau perubahan aplikasi sistem":

  • Dynamic Form Loading saat kategori dipilih
  • Auto-Assign ke admin@helpdesk.local
  • Data Storage di tabel ticket_sdlc_data
  • View & Download: HTML dan PDF

3.4 Notifikasi

  • Real-time notifications
  • Notification bell dengan badge
  • Mark as read / Mark all as read

3.5 Email Notifications

  • New Ticket → Admin
  • Ticket Assigned → Admin
  • Ticket Updated → User
  • Password Reset → User

3.6 Reporting

  • PDF Export (semua tiket)
  • Excel/CSV Export
  • Description lengkap tanpa dipotong

3.7 User Management (Admin Only)

  • List Users
  • Create User
  • Update User
  • Delete User

3.8 Dashboard & Analytics

  • User Dashboard: statistik tiket sendiri
  • Admin Dashboard: statistik semua tiket, charts (pie & bar)

3.9 Panduan/Guideline

  • Interactive Guide dalam iframe
  • Bilingual (Indonesia/English)
  • Responsive untuk desktop dan mobile
  • Auto reset ke slide 1 saat dibuka

6. Proses Bisnis

6.1 Flow Create Ticket

  1. User login ke sistem
  2. User pilih "Create Ticket"
  3. User isi form (kategori, deskripsi, prioritas, attachment)
  4. Sistem generate nomor tiket otomatis (T00001, T00002, ...)
  5. Sistem assign tiket (SDLC → auto ke admin@helpdesk.local)
  6. Sistem simpan ke database
  7. Sistem kirim email notifikasi ke admin
  8. Sistem buat notifikasi untuk admin

6.2 Flow Password Reset

  1. User klik "Forgot Password?"
  2. User input email
  3. Sistem generate token unik (64 karakter hex)
  4. Sistem simpan token (expires 1 jam)
  5. Sistem kirim email dengan link reset
  6. User klik link di email
  7. Sistem verifikasi token
  8. User input password baru
  9. Sistem update password
  10. Sistem mark token sebagai used

8. Setup & Instalasi

8.1 Requirements

  • PHP 7.4+
  • MySQL 5.7+ atau MariaDB 10.2+
  • Apache/Nginx
  • PHP Extensions: PDO, PDO_MySQL, mbstring, GD, OpenSSL

8.2 Instalasi Database

  1. Buat database di hosting/phpMyAdmin
  2. Import helpdesk_db.sql
  3. Import update_database_sdlc_v2.sql
  4. Import update_database_password_reset.sql
  5. Verifikasi semua tabel sudah dibuat

8.3 Instalasi File

  1. Upload semua file ke web server
  2. Set permission folder uploads/ ke 755 atau 777
  3. Edit config.php (update credentials & SITE_URL)
  4. Test koneksi database

9. Security Best Practices

9.1 Password Security

  • Password minimum 6 karakter
  • Password di-hash menggunakan bcrypt
  • Reset token: 64 karakter random, expires 1 jam, single-use

9.2 Input Validation

  • Semua input di-sanitize menggunakan clean_input()
  • SQL injection prevention: PDO prepared statements
  • XSS prevention: htmlspecialchars()

9.3 Access Control

  • Role-based access control (user/admin)
  • User hanya bisa akses tiket sendiri
  • Admin bisa akses semua tiket

10. Troubleshooting

10.1 Database Connection Error

Solusi:
1. Cek credentials di config.php
2. Cek database sudah dibuat
3. Cek user database punya permission
4. Cek firewall/network

10.2 Email Tidak Terkirim

Solusi:
1. Cek PHP mail() function enabled
2. Cek SPF/DKIM/DMARC setup
3. Cek spam folder
4. Cek email server logs

10.3 File Upload Error

Solusi:
1. Cek permission folder uploads/ (755 atau 777)
2. Cek php.ini upload_max_filesize
3. Cek disk space
4. Cek file type allowed

11. Maintenance

11.1 Backup Database

Lakukan backup database secara berkala:

  • Daily backup untuk production
  • Weekly backup untuk development

11.2 Cleanup Old Data

  • Hapus token password reset yang sudah expired (lebih dari 1 hari)
  • Archive tiket yang sudah "Done" lebih dari 1 tahun (optional)

11.3 Update Password

  • Ubah password default admin setelah instalasi
  • Rekomendasi: ubah password setiap 3-6 bulan
